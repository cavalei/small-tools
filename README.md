# 小工具合集

一些自己写的小工具。单文件、免安装、双击即用，不联网、不写注册表。

## 收录

| 工具 | 用途 | 状态 |
|---|---|---|
| **TxtReader** | 超长 txt 阅读器，分段加载不卡顿，支持日间/夜间配色 | 可用 |
| **HashChecker** | 文件哈希校验，图形界面 + 命令行两种用法 | 可用 |
| **压缩包密码恢复** | 忘记 zip 密码时本地暴力尝试，纯 CPU 计算 | 可用 |

## 说明

- 全部为单文件程序，解压即用，不需要安装运行时
- 不联网、不上传任何文件、不写注册表
- 面向 Windows 10 / 11 x64
